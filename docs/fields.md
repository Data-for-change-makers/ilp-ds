# ILP-DS fields and code lists

Version 0.7-draft. Generated by `tools/build_schema.py` from `schema/fields.csv` and `codelists/`;
do not edit this page by hand.

Required: **yes** for every record; **building** or **not building** where it depends on the kind.
Visibility: **public**; **restricted** (published only once listed in `published-with-consent`);
**internal** (never published). See the [specification](specification.md#who-sees-what).

## Structure

Fields that hold the records together.

| Field | Applies to | Type | Required | Visibility | Source | Definition |
| --- | --- | --- | --- | --- | --- | --- |
| `kind` | all | [code:kind](#kind) | yes | public | ILP-DS | The type of record: an area, cluster or site, a mineral extraction site, a building, or a route or network of infrastructure. |
| `parent` | cluster, site, mineral-extraction, infrastructure, building | id | building | public | ILP-DS | The id of the record one level up, in the same file. Required for a building. |
| `serves` | infrastructure | ids | no | public | ILP-DS | The ids of the areas, clusters and sites the infrastructure serves or connects, in the same file. |
| `published-with-consent` | all | field-names | no | public | ILP-DS | The restricted fields that the owner or planning authority has agreed may be published for this record. |
